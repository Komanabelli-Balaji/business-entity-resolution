# Business Entity Resolution Hackathon

## Project Structure
- `src/`: Core pipeline logic and reusable modules.
- `experiments/`: Reproducible experiment scripts.
- `notebooks/`: Exploratory data analysis, visualization, and training experiments.
- `outputs/`: Final outputs (`matching_results.tsv`, `candidate_pairs.tsv`).
- `requirements.txt`: Final submission dependencies.
- `AGENT.md`: Rules and guidelines.
- `TASKS.md`: Execution plan and task tracking.
